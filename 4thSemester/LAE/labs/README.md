# LAE 2526 Summer Semester

Repository for the laboratory classes of LAE (Managed Runtime Enviorement). This will include, in separate folders, each lab with a markdown file containg the Answers.

## Lesson 02, 20/02/2026
- Java compiler
- Kotlin compiler
- JVM
- Gradle

Objectives:

- Experiment with interoperability between Kotlin and Java on the JVM.
- Understand .class file generation, dependency resolution, CLASSPATH, and lazy class loading.
- Explore how Gradle manages dependencies and builds a runnable JVM application.

## Lesson 05, 27/02/2026
- JVM Bytecode
- kotlinc bytecode VS javac bytecode
- definition of signature

Objectives:

- Understand the under the hood process of compiling kotlin and java.
- Learn how to interpret JVM Bytecode and match it to a jvm language (kotlin or java)
